# Selector & DOM Observation Guide

Ego Lite provides a semantic snapshot and locator system designed for robust AI agent interaction without relying on fragile XPath or raw coordinates.

---

## 1. Semantic Snapshot (`page.snapshot()`)

A snapshot converts the current webpage DOM into an accessible text tree. Nodes are annotated with references (e.g., `@12` or `ref=21`).

```js
// Viewport snapshot (default)
console.log(await page.snapshot());

// Full page snapshot (scrolls through the page)
console.log(await page.snapshot({ scope: "full_page" }));

// Subtree snapshot (focusing on an iframe)
console.log(await page.snapshot({ scope: "subtree", root: "@12" }));
```

> [!TIP]
> Always take a snapshot at the end of a round script (`console.log(await page.snapshot())`). This prints the current state of the page directly into the execution output, allowing your next turn to immediately read the available `@ref` IDs without needing an extra round just to observe.

---

## 2. Selector Types

Element actions (`page.click()`, `page.fill()`, `page.hover()`, etc.) accept the following selector formats:

### 1. Snapshot References (Fastest & Most Reliable)
Use the refs generated by `page.snapshot()`:
```js
await page.click("@21", { label: "Click search button" });
await page.fill("@15", "Antigravity AI");
```

### 2. Semantic Role Locators (`loc=role:`)
Matches by accessible ARIA role and accessible name:
```js
await page.click("loc=role:button[name='Sign in']", { label: "Sign in" });
await page.click("loc=role:link[name*='Documentation']", { label: "Open docs" });
```

### 3. Text Locators (`text=...`)
- **Substring (Case-Insensitive)**:
  ```js
  await page.click("text=Submit", { label: "Click Submit" });
  ```
- **Exact Match (Quoted, Case-Sensitive)**:
  ```js
  await page.click('text="Save changes"', { label: "Save changes" });
  ```

### 4. CSS Locators (`loc=css:` or raw CSS)
```js
await page.fill("loc=css:input#username", "admin");
await page.click("form.auth-form button[type='submit']");
```

### 5. Playwright Subsets
- Chaining with `:has-text(...)`:
  ```js
  await page.click("button:has-text('Confirm')", { label: "Confirm action" });
  ```
- Indexing with `>> nth=N`:
  ```js
  await page.click("div.item-card >> nth=0", { label: "Select first item" });
  ```

---

## 3. Working with Iframes

When dealing with embedded widgets or iframes:
1. In the top-level snapshot, find the `iframe` element and note its ref (e.g., `@8`).
2. Run a subtree snapshot:
   ```js
   console.log(await page.snapshot({ scope: "subtree", root: "@8" }));
   ```
3. Use the refs inside that subtree for actions. Actions will automatically route to the corresponding frame.

---

## 4. Best Practices for Selectors

- **Prefer `@ref` or `loc=role:`**: Semantic selectors are resilient against layout shifts and obfuscated CSS classes.
- **Ambiguity**: If a selector matches multiple actionable elements, the action will throw an ambiguity error. Narrow the selector using parent scopes or `>> nth=N`.
- **Auto-scroll**: Pointer actions (`click`, `hover`, `fill`) automatically scroll the target element into view. Do not write manual scroll loops unless visually inspecting canvas or lazy-loaded feeds.
